<h3>Data Journal for "We Mapped the Hottest Ground Surfaces in SC Cities"</h3>

<p>
This repository contains the core Jupyter Notebooks used in the analysis for our Land Surface Temperature (LST) story. The notebooks guide users through cleaning, converting, and comparing satellite thermal data. Please note that this repository does not include the satellite imagery itself. To replicate the analysis, you can download the LST imagery from <a href="https://earthexplorer.usgs.gov/">USGS Earth Explorer</a>.
</p>
